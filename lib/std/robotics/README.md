# Standard robotics vocabulary (S1-11)

`vocabulary.inv` is the shipped `std::robotics` module. Its generic records are ordinary checked Invar types. `T` is a scalar identity; `F`, `Camera`, `Parent`, and `Child` are nominal frames; `U` is a unit; and `N` is an inline joint count from 1 to 64. `FixedArray<T,N>` is type-only before M4-01. `f32` and `f64` port identities and `i64` nanosecond stamps are also type-only before their runtime milestones. The checker rejects their use in executable functions; `check_port_types` validates wire declarations without exposing an executable program.

`px` is nominal: it only converts to itself. Camera width and height are positive u32 pixel counts; focal and center coordinates use px at scalar T. Distortion coefficients are dimensionless exact decimal strings. The three distortion cases are `none`, five-coefficient `plumb_bob`, and four-coefficient `equidistant`. Quaternion unit norm is a declared property; this module does not claim a numeric proof of it. `Pose<T,F,Child>` has translation in F and rotation from Child to F; `compose_pose_type` checks the shared frame and scalar. Joint position units come from each declared robot joint kind (rad or m), not one unit for the entire vector.

`layout-header-v1.h.in` is the canonical C layout template, with scalar and joint count substituted only after validation. Frames remain compile-time identities; joint names are represented by indices into the declared robot-model name table in the C record. A trajectory has 64 inline waypoint slots and an explicit count. `ros-mapping-v1.json` is data for S1-04 conversion generation. Its scale rules use rational numerator/denominator strings and a symbolic power of π, so no host floating-point approximation enters the compile-time IR. CameraInfo pixel coordinates remain px; other ROS numeric fields use REP-103 SI units.

`Stamped<X>` carries a `frame_id` index into the declared frame-name table, in addition to its nanosecond timestamp and payload. S1-04 resolves that index to the declared ROS `frame_id` string.

`from_ros_joint_state` is the release-reachable pure conversion boundary for caller-supplied ROS message fields. It requires exactly the declared ordered names, full position/velocity/effort arrays, and finite values before publishing a result. All failures return registered `S1701` with no suggested fix. The additional `external` reachability registry is `schema/diagnostic-codes-external-v1.json`. This boundary is not a live ROS transport check.
