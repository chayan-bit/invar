# S1-12 - End to end with Invar implementations

Release: v0.3 (milestone S1); planning contract, to be expanded into a full contract before implementation.

Dependencies: R1-02, R2-02, S1-09.

## Goal

Replace Pinocchio in the S1-06 cell with Invar-compiled kinematics (R1-02) under a differential test with a measured speedup, and ship the result as a Nix image with a full evidence report.

## Motivation

Policy: an Invar implementation replaces a reference implementation only after a differential test shows identical results under the declared numeric policy and a measured speedup; this is Invar's engine-agreement invariant applied one level up.

## Scope

- Swap the `pinocchio_kinematics` component for an `impl invar` component generated by R1-02 for each arm, keeping the manifest ports identical.
- Differential test against Pinocchio on the S1-06 trajectories and a randomized joint-space sample set, under the declared numeric policy and tolerance.
- Benchmark forward kinematics, Jacobian and inverse dynamics per arm against Pinocchio, reporting median and IQR.
- Build the product image (S1-09) and generate the R2-02 evidence report including graph checks, timing results and the differential test.

## Acceptance sketch

- Integration test binary `issue_s1_12_invar_end_to_end`: the reach-and-place task passes on both arms with the Invar component, the differential test passes, and the measured speedup is reported; if no speedup is measured, Pinocchio stays and the report says so.

## Out of scope

Replacing cuRobo, real hardware, certification sign-off.
