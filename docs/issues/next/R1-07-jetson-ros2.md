# R1-07 - NVIDIA Jetson Orin target plus ROS 2 and C++ integration

Release: v0.2 (milestone R1); planning contract, to be expanded into a full contract before implementation.

Dependencies: R1-03, S1-04.

## Goal

Run Invar kernels on NVIDIA Jetson Orin and integrate with ROS 2 and C++ robot stacks.

## Motivation

Invar's robotics direction is an OEM supplier model: each new manufacturer's hardware should be cheap to support, because robot-specific facts become typed compiler inputs instead of per-customer hand-written code.

## Scope

- CUDA on aarch64 Jetson Orin through the existing CUDA backend with an explicit sm target.
- A C++ header over the L1-04 C ABI and a ROS 2 node example that calls Invar kernels on messages.
- Cross-compilation or on-device build documented in a Nix-reproducible way.

## Acceptance sketch

- Qualified with the M5-01 harness on Jetson Orin (correctness plus library-ratio report).
- The ROS 2 example runs end to end and matches the reference evaluator.
- Integration test binary `issue_r1_07_jetson_ros2`.

## Out of scope

No ROS 1, no DDS implementation, no other embedded GPU vendors.
